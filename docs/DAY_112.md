# Day 112: AI DevOps Copilot Platform

## Overview
The AI DevOps Copilot Platform transforms DevOpsEase into an intelligent reasoning engine. Rather than functioning as a standard generic LLM chatbot, the AI layer consumes structured metadata generated by existing core subsystems (Build Engine, Platform Resilience, Observability) to deliver explainable, actionable insights and automatic failure diagnostics.

## Key Architectural Decisions

### 1. Unified Intelligence via Knowledge Engine
To prevent hallucination, eliminate database thrashing, and control token usage, all AI interactions run through the centralized `KnowledgeEngine`.
- Constructs modular objects: `RepositorySummary`, `PlatformHealthSummary`, `DeploymentSummary`.
- Aggressively redacts secrets using regex patterns before injecting state into prompts.

### 2. Intent Routing & Skills
The architecture rejects monolithic prompt engineering. User inputs are evaluated by the `IntentRouter` which dispatches execution to isolated AI Skills:
- `FailureAnalysisSkill`
- `ArchitectureReviewSkill`
- `GeneralChatSkill`
This ensures adding new AI capabilities (e.g., Cost Review) doesn't bloat existing prompt code.

### 3. Provider Independence
A strict `BaseProvider` interface separates business logic from AI vendor SDKs. We have implemented `GeminiProvider` using the official `@google/genai` library (`gemini-2.5-flash`), supporting streaming, embeddings, and token counts, while ensuring OpenAI or Local models can be swapped in instantly.

### 4. Structured Explainability
Every AI output is processed by `PromptOrchestrator` forcing strict JSON schemas. 
- The `CopilotMessage` model persists not just the response, but the `skillInvoked`, `confidence` score, and the specific `knowledgeObjectsUsed`. 
- This metadata is piped directly to the UI, ensuring users always understand *why* the AI made a decision and *what* evidence was evaluated.

### 5. Asynchronous Streaming
The Copilot interface uses highly responsive Server-Sent Events (SSE). The `CopilotPage.tsx` interface reads streams in real-time, providing immediate feedback alongside structured, proactive `CopilotRecommendations` formatted neatly into action cards.
